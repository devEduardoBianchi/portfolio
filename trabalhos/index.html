01 / SISTEMA DE CHAMADOS

Nexo Desk.

Criei o Nexo Desk para organizar o trabalho de suporte em um só lugar. Dá para acompanhar chamados, prioridades e prazos, usar filtros e quadro por status, registrar notas e consultar o histórico. Ações em lote podem ser desfeitas por 60 segundos.

A demonstração pública usa dados fictícios e salva as alterações neste navegador.

HTML · CSS · JavaScript · GSAP
Versão local: Node.js · Express · SQLite

02 / SITE DE INFORMÁTICA

Nexo Oficina Digital.

Um site conceitual para uma empresa de informática e assistência técnica. Reúne serviços, catálogo com busca, filtros e ordenação, Blog e uma página dedicada ao reparo de notebooks.

Marca, produtos e contatos fictícios. O atendimento é simulado; nenhuma mensagem é enviada.

HTML · CSS · JavaScript · GSAP

03 / APLICAÇÃO WEB

Entre Cenas.

Um diário para quem gosta de cinema. Nele, dá para descobrir filmes, montar uma lista pessoal, dar notas e acompanhar estatísticas da coleção. O catálogo TMDb é opcional.

HTML · CSS · JavaScript · GSAP · localStorage · API TMDb opcional

05 / ESTUDO DE INTERFACE

Price Cards.

Um estudo de interface para comparar planos de hospedagem. A página resume as opções e sugere um plano conforme a quantidade de sites e a necessidade de e-mail personalizado. O Premium aparece como opção recomendada para pequenos projetos.

HTML · CSS · JavaScript · Design responsivo
